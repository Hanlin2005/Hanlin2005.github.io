Liberata Agent Simulation

Tools: Python

I built an agent-based simulation of Liberata’s peer-review marketplace. Each agent has a quality talent and a speed talent. A paper’s quality is drawn from a Gaussian around the author’s quality talent, and that quality sets both how fast the paper accrues value and how much a review can add. Each timestep the agent either writes or reviews. It cannot do both at once.

A paper is listed one timestep after it is published, and it can be reviewed once. The market can award it to the eligible reviewer with the highest expected claim value. The author’s offer to each reviewer depends on that reviewer’s history of how much their reviews improve a paper. In continuous mode the reviewer chooses when to stop. In discrete mode the reviewer locks in a good-faith or bad-faith length at the start, and a bad-faith review is a single timestep. Review effort raises the paper’s accrual, with most of the gain around the good-faith threshold.

The agents can be random, heuristic, tabular Q-learning, or a deep Q-network. A run records who wrote, who reviewed, good-faith and bad-faith reviews, academic capital, and inequality. The scientometrics library is a separate project. It computes the metrics this marketplace is built around.
