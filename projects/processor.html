Pipelined Processor

Tools: Verilog, Python

For ECE 350 I built a processor in Verilog, in four checkpoints. The ALU does add, subtract, AND, OR, logical shift left, and arithmetic shift right, and it reports not-equal, less-than, and overflow. The register file holds 32 registers. Multiply and divide are separate multi-cycle units: the processor starts one, then stalls until the result is ready.

The last checkpoint is a five-stage pipeline: fetch, decode, execute, memory, and writeback. It bypasses results that a later instruction needs immediately, and it stalls when a load is still in flight and the next instruction reads that register.

I also wrote a Python assembler for the course instruction set. It can accept extra instructions, but the FPGA Pac-Man game does not use one to draw sprites. That game is a separate project. It uses the normal instructions and talks to the display through an input register and an output register.
