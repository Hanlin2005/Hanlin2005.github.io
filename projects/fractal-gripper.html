Fractal-Shaped Robotic Gripper in URDF

July 2025

Tools: Fusion, PyBullet

PyBullet simulation of the gripper.

I modelled a fractal-shaped robotic gripper in Fusion and simulated it in PyBullet. The shape repeats at smaller scales, so the fingers can wrap around an object with more than one size of contact.

Fusion was the model. From there I exported a URDF, which lists the links, the joints, and the collision geometry. PyBullet reads that file and lets the joints move, which is the clip above. The simulation is where I could see the hand close before committing the design to hardware.

The project is the path from a CAD model to a robot description that a simulator will accept. July 2025 is when I had the gripper running in that loop.
